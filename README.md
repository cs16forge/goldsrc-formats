# goldsrc-formats

**Practical notes on Counter-Strike 1.6 / Half-Life (GoldSrc) file formats and engine behaviour**
— the parts that are not written down anywhere else, or are written down wrong.

Each page states a format or a rule, gives the numbers, lists the ways it breaks, and says
**how it was verified**. Where we did not verify something, the page says so.

> These notes come from building [cs16forge.com](https://cs16forge.com/) — a catalogue of skins,
> maps, HUDs and menu backgrounds for CS 1.6 players, with a
> [browser workshop](https://cs16forge.com/workshop/) that reads and edits the game folder directly.
> If you are a player rather than a tool author, the site is what you want.

## Engine notes

Short, single-fact pages.

| Note | One line |
|---|---|
| [File size `16777215` in the resource list](notes/resourcelist-size-0xffffff.md) | it is a 24-bit −1, "size unknown", not 16 MB |
| [Face winding in BSP30 is clockwise](notes/face-winding-clockwise.md) | write it the other way and the engine draws nothing — and your own viewer will not notice |
| [Lightmap limit: 324 luxels per face](notes/lightmap-324-luxels.md) | extents are in texels, so a big *texture* on a small quad still overflows |
| [Embedded vs WAD textures in a BSP](notes/bsp-embedded-vs-wad-textures.md) | the flag is a zero mip offset in the miptex, not −1 in the directory |
| [Do not append to a `.mdl`](notes/mdl-texturedataindex-trap.md) | the engine keeps only the bytes before `texturedataindex` |
| [What `dev_overview` actually draws](notes/dev-overview-what-engine-draws.md) | one height slab of up-facing world faces |

## Machine-readable

[`schemas/`](schemas/) — [Kaitai Struct](https://kaitai.io/) descriptions of the binary formats above
(`wad3.ksy`, `spr_goldsrc.ksy`). Each one is compiled and run against a
generated sample before it is committed.

## Ground rules of this repository

- **No game assets.** No Valve files, no community models, maps or sprites. Examples are hex
  dumps we typed or files generated by code.
- **Sources are linked, not copied.** Where a fact comes from ReHLDS, ReGameDLL_CS, Xash3D FWGS,
  the Half-Life SDK or NextClient, the page links to the file and function.
- **Corrections are welcome.** Open an issue with a counter-example. This is not a support
  channel for the website.
